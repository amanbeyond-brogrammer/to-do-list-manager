# 📝 To-Do List Manager (C++)

A simple, console-based task manager built from scratch in C++ as my first mini-project.

## ✨ Features
- ➕ Add new tasks
- 👀 View all pending tasks
- ❌ Delete tasks by number
- 🧹 Clean menu-driven interface

## 🚀 How to Run
1. Compile: `g++ todo.cpp -o todo`
2. Run: `./todo` (or `todo.exe` on Windows)

## 📚 What I Learned
- Using `vector` for dynamic data storage
- Handling user input with `cin` and `getline`
- Building a menu-driven console app
- Pushing my first real project to GitHub
